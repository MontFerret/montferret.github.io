# JetBrains IDEs

The Ferret plugin for IntelliJ IDEA and GoLand is in development. It has no published JetBrains Marketplace listing or tagged plugin release. The development build includes language assistance, Run, and Debug through the Ferret daemon. See the [Editorium JetBrains guide](https://github.com/MontFerret/editorium/tree/main/extensions/jetbrains) for tested IDE versions, source builds, and current limitations.

For a released editor integration, see [Visual Studio Code]({{< ref "/docs/tools/visual-studio-code" >}}).
